Semantic understanding meets exact keyword matching.

Fractal combines Gemini semantic search with Elasticsearch full-text retrieval. Reciprocal Rank Fusion merges their results, bringing both meaning and precise terms into the final ranking.

Implementation

A Next.js frontend sits over an Express search service. The retrieval layer queries the semantic and lexical paths, then combines ranked results using RRF.

COLLABORATION · ATLASSIAN FORGE

HuddleMeet inside Confluence.

Repository↗

ReactTypeScriptAtlassian ForgeJitsi MeetWeb Speech API

Video conversations and live transcripts, in the page where the work happens.

Huddle is a Confluence macro for starting and joining video meetings without leaving a document. The documented design combines an embedded Jitsi meeting with a React interface for transcription, chat, and meeting controls.

Architecture

Forge resolvers create and end rooms, while Forge Storage tracks the active meeting by Confluence page ID. The Custom UI communicates through Forge Bridge; video is embedded in a separate iframe.

Design constraints

Transcription uses the Web Speech API independently of Jitsi, so it has its own microphone toggle. Browser support varies, and Forge’s content security policy limits direct control of the video iframe.

The public repository currently provides the architecture, setup documentation, and Forge configuration.
