INFORMATION RETRIEVAL

FractalHybrid search.

Source↗

Semantic understanding meets exact keyword matching.

Fractal combines Gemini semantic search with Elasticsearch full-text retrieval. Reciprocal Rank Fusion merges their results, bringing both meaning and precise terms into the final ranking.

GeminiElasticsearchNext.jsExpress

Implementation+

A Next.js frontend sits over an Express search service. The retrieval layer queries the semantic and lexical paths, then combines ranked results using RRF.

AVIATION DATA SYSTEMS

AeroTrack AIFlight data, connected.

Source↗

An aviation pipeline from live flight observations to forecasts and natural-language queries.

A custom Fivetran connector ingests OpenSky flight data into BigQuery. Vertex AI AutoML supports predictive modelling, while a Gemini agent provides a conversational interface to the data.

Fivetran SDKBigQueryVertex AIGeminiNext.js

Implementation+

The project connects data engineering, modelling, and a Next.js interface. BigQuery holds the flight records and scheduling logic, with separate model and agent layers consuming the warehouse.
