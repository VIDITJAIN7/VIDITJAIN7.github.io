# Visual component credits

The canvas artwork in `script.js` adapts these components by Ali Imam (@designali-in), retrieved through the official 21st.dev MCP on 18 September 2026:

- [Dot Sphere](https://21st.dev/@designali-in/components/dot-sphere) — demo ID 9379. The staggered lattice, distance-based alpha, and dot-radius falloff are adapted to responsive containers.
- [Mechanical Waves](https://21st.dev/@designali-in/components/mechanical-waves) — demo ID 9278. The Gaussian peak field and quadratic line interpolation are adapted into a deterministic surface with gentle periodic drift.

The React lifecycle wrappers were replaced with DOM-native canvas initialization. Local adaptations add a shared animation loop, visibility suspension, responsive sizing, bounded pixel density, motion preferences, and smoothed pointer response. Preview images, videos, and demo layouts from the marketplace are not bundled.

The site layout, case-study presentation, navigation behavior, and explanatory SVG diagrams are custom. Research illustrations are labelled as conceptual rather than experimental output.
